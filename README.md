# 📊 Pesquisa de Atendimento — TudoWeb

Projeto em Python desenvolvido para uma atividade de programação. O objetivo é realizar uma pesquisa de opinião para avaliar a satisfação dos clientes com o atendimento da empresa TudoWeb.

## 🚀 Funcionalidades

- Coleta o nome e a idade dos entrevistados.
- Registra a opinião sobre o atendimento.
- Utiliza `for` para repetir a pesquisa.
- Utiliza `if` e `elif` para verificar as respostas.
- Contabiliza as avaliações **EXCELENTE** e **RUIM**.
- Exibe o resultado final da pesquisa.

## 📝 Opções de resposta

| Código | Opinião |
|---|---|
| 1 | Excelente |
| 2 | Bom |
| 3 | Ruim |

## 🛠️ Tecnologias utilizadas

- Python 3

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo Python em um editor, como o VS Code.
3. Execute o programa pelo terminal:

```bash
python pesquisa.py
```

4. Informe os dados solicitados para cada entrevistado.
5. Confira o resultado exibido ao final.

*Observação: se o arquivo Python tiver outro nome, substitua `pesquisa.py` pelo nome correto.*

## 🧪 Testes

O programa pode ser executado com 10 entrevistados para testar seu funcionamento. Na versão final da pesquisa, o laço de repetição deve ser configurado para receber 50 entrevistados, conforme solicitado na atividade.

## 🎯 Objetivo acadêmico

Praticar os conceitos básicos de Python, incluindo entrada de dados, variáveis, estruturas de repetição, estruturas de decisão e contadores.
